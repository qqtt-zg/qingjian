# 手机词汇与 AI 答疑

个人版 Android App 0.2.10-dev 打开后显示学习首页，底部有「今日、词汇、复习、设置」。朗读操作与原「我的」中的选项已合并到统一设置页。

## 连接电脑朗读

点击底部「设置」，在「朗读与连接」分组扫码连接电脑，或使用已保存的地址启动接收。首页只显示音色和音量摘要，不提供重复的调节控件。

点击唯一的「朗读设置」入口，可以更改音色、试听、调节音量、选择增强预设，以及查看后台设置和运行诊断。手动填写完整配对地址后，点击「保存配对地址」，再返回设置首页点击连接才会生效；保存本身不会重新连接或中断当前会话。设置首页保留四个底部标签，切换页面不会主动停止接收。

「朗读设置」的语速范围为 0.50×～2.00×，每次可调整 0.05×，默认 1.00×；也可点 0.75×、正常、1.25× 或 1.50× 快捷选择。设置会自动保存，从下一条试听或电脑发来的朗读生效，不会中途改变当前播放。设置首页只显示当前语速摘要。

朗读设置、AI 设置、应用更新、数据与关于和答疑页均使用左上角返回箭头；也可使用系统返回手势或返回键。

电脑发来的英文会保存到词汇本。收到请求和完整播放分别计数；被打断的播放不计为播放完成。这些记录只表示接触情况，不表示已经掌握。内置试听句不自动收录。

## 通过电脑更新应用

首次需手动覆盖安装支持更新的新版 App。之后，连接电脑成功时会自动检查电脑提供的新版本；在「设置 → 应用更新」查看结果，也可以手动检查。

发现新版本后点击「下载更新」，保持电脑连接服务在线。下载完成后点「安装更新」，首次按系统提示允许青简安装未知应用，返回后再点「安装更新」确认。应用会校验安装包，正常覆盖安装保留词汇、笔记、配对与配置；无需先卸载。

0.2.10-dev 起，更新会分段下载，显示进度、已下载大小和平均速度。可以暂停，网络中断后也会保留已下载部分，点击「继续下载」恢复；「从头重新下载」会主动丢弃已有部分。完整性校验发现数据损坏时会丢弃损坏文件。请尽量保持 App 在前台；断开连接或应用进程被系统结束后，已写入的部分仍可在下次继续。断点续传需电脑连接工具同时升级，旧工具仍可完整下载，但无法从中间继续。

网络中断与安装包签名不一致会分别提示。出现下载错误并不代表签名有问题；只有完整包经过校验后才会允许进入系统安装流程。

页面会明确显示目标版本和构建号。已有当前目标版本的下载缓存时显示「安装更新」，也可以点击「重新下载安装包」。发现不同安装包后需重新下载；旧缓存或校验失败的包不会继续显示为可安装。旧版用户若安装页仍显示上一版本，请先退出系统安装界面，再回到应用中检查更新并下载。

页面显示的是已配对电脑提供的版本。电脑没有准备安装包时会提示「电脑尚未提供安装包」；旧版电脑工具需要先更新并重启手机连接服务。

## 词汇与离线复习

在「词汇」搜索英文或中文笔记，也可以手动添加词或短语。点击「编辑中文笔记」保存你确认的中文意思。当前不会自动把某一个 AI 回答写成确定词义。

点击词汇卡片上的「学习这个词」，可以选择「词性与用法」「搭配与例句」或「常见错误」。选择后会打开带问题草稿的答疑页，先查看或修改，再点「发送问题」；不会因为进入页面或选择方向就自动请求 AI。

想比较两个词时，在「相近词怎么选？」填写另一个词，例如从 realize 填入 implement，再补充自己的句子或想表达的意思，点击「准备辨析问题」。可以继续追问，也可以断网时只保存问题。学习详情显示最近两条已保存讲解的摘要，「离线查看完整讲解」进入该词的本机对话历史；已有笔记、计数和对话会保留。

有中文笔记后，可到「复习」开始一轮最多五个词的卡片：先回忆，点击「查看笔记」，再选择「还需巩固」或「这次记住了」。这是自评，不是考试成绩。

## 离线测验与错题

「复习 → 离线测验」提供「词义选择」和「中文拼写」，按你保存的中文笔记出题，每轮最多五题，不请求 AI。选择题需要至少两条不同的中文笔记；拼写题会跳过多个词共享同一笔记的条目，减少答案歧义。拼写忽略英文大小写与多余空格，标点仍需与条目一致。

提交后显示本题答案和反馈，完成后显示本轮结果。两种题型分别累计作答与答对次数，不增加卡片自评次数，也不代表已经掌握该词。页面重建不会重复计分。

「错题本与记录」显示各词该题型最近一次仍答错的记录，可以只重测错题。同一词同类题后续答对，会移出待巩固列表，过去的作答仍保留在累计统计中。题目依据的是出题时的笔记快照，修改笔记不会改写旧成绩；遇到含义疑问可以进入该词学习页继续提问。

## 录音跟读与自评

在词汇学习详情、卡片复习、测验反馈中点击「录音跟读」，或从「复习 → 选择词汇跟读」搜索并选择条目。先点「听示范」，等朗读结束，再点「开始录音」。首次会请求麦克风权限；进入页面本身不会录音。

每次最多录制 30 秒，点「停止录音」后可试听，再点「保存本次录音」。声音较弱时会提示检查录音质量，该提示不表示发音是否正确。保存后可回放、选择「还需练习／比较满意」自评，或删除单段录音；页面显示最近保存的 20 段。离开页面会取消进行中的录音并停止回放。

录音保存在手机私有目录，不会上传。当前按用户选择先提供跟读和自评，自动发音评估待后续配置专门服务；页面明确显示未评估，不会把自评换算成发音分数。

## 配置 AI

在「设置 → 配置与测试 AI」填写自己的 API 地址、模型 ID 和 API Key。地址按服务商文档填写，例如基础路径中要求 `/v1` 时要包含它，也可以直接填写完整的 Chat Completions 地址。

点「测试连接」会向你填写的服务发送一条短请求，可能产生服务商费用。测试成功后点击「保存配置」。本版支持 HTTPS 的 OpenAI 兼容文字接口，暂不支持仅提供其他协议的服务。

测试时会自动显示状态区域，包含加载动画、请求阶段和已等待秒数；可以点击「取消测试」。结束后保留「测试成功」或「测试失败」、耗时和失败说明，保存配置不会覆盖刚才的测试结果。修改地址、模型或密钥后需要重新测试；测试期间这些字段暂不可编辑。成功表示收到了模型的文字回答，不表示口语音频评估可用。

密钥加密保存在手机，不包含在安装包中；清除 AI 配置不会清除词汇。无需电脑开机即可联网答疑。

## 提问与追问

首页点击「问一问 AI 老师」，或在词汇的学习详情中选择学习方向、准备辨析问题或自由提问。词汇入口会携带当前英文、中文笔记和相关对话，不会发送整份词汇本或电脑配对地址。

可以询问词性、搭配、两个词如何区分，或者给出自己的句子继续追问。AI 回答可能有误，重要用法需核实。AI 回答不会自动保存为考试成绩，也不能代替录音发音评估。

完全断网时可看已收到的回答，点击「只保存问题，稍后再问」。联网后点「发送／重试最近保存的问题」。发送失败的问题同样保留；App 不会自行反复重试。

## 当前版本范围

已提供词汇记录、扩展学习、卡片自评、离线笔记测验、错题记录、录音跟读、自评和联网文字答疑。结构化辨析资料包、每日/每周总结、AI 语境出题与自动发音评分仍在后续阶段。

「设置 → 数据与关于」可查看当前版本、开源许可与第三方说明；其中的「清空本机学习记录」会删除词汇、笔记、全部 AI 对话、测验与跟读录音，保留电脑配对、音色和 AI 配置。删除前需要确认。覆盖安装新版会迁移保留原词汇与对话。
