## 译词

每个候选右侧最多一条译词，附词性。语言由「设置 → 候选」的「译文」决定，英语、日语、西班牙语、越南语或德语，一次只有一种；
选「不显示译文」则候选旁不出译词，生词标记与释义兜底也停，翻译选中的文字仍可用（译成英语）。
Windows 上可在同一页关掉「译词显示词性」：候选旁只留译词，不再显示 v. / n. / adj. 等标注（`develop` 而非 `v. develop`）。

- 英语：`开发` → v. develop · v. exploit。
- 日语按汉字段标注平假名：`开发` → v. 開発(かいはつ)する。
- 西班牙语：`开发` → v. desarrollar。
- 越南语：`开发` → v. phát triển。
- 德语：`房子` → n. das Haus。

没有译词的候选留空，不显示占位符。随包释义表覆盖整个词库；打开 [云联想](../cloud/index.md) 后，表中没有的词在输出后会自动补充一条。

## 点击小喇叭朗读（个人修改版）

Windows 修改版使用青简候选窗口时，有英文译词的中文候选、英文单词候选的行末显示小喇叭。点击中文候选的喇叭读英文译词；点击 `control`、`controlled` 等英文候选的喇叭读单词本身，不读右侧中文释义，尚无释义时也可朗读。点击不选词、不上屏、不清空拼音，可以重复点击重听；词性标签不读出。

鼠标移到喇叭上会变色并显示手形光标，按住时颜色加深；在喇叭上松开发送，拖出后松开取消。候选窗显示发送中、已发送或发送失败的提示。“已发送”表示电脑已交给连接工具，实际播放请在手机上确认。

也可在「设置 → 快捷键 → 朗读候选英文」录制修饰键，例如 `Ctrl + 1` 朗读当前页第一个候选，`Ctrl + 2` 朗读第二个，支持 `1`～`9`。与点击小喇叭相同：英文候选读单词本身，中文候选读英文译词，不上屏、不清空输入，重复按可重听；翻页后序号对应新的一页。没有候选或没有可读英文时不发送。录制时按 `Backspace` 可关闭。

朗读快捷键默认未设置，以保留原有按键习惯。请先把原来占用同一修饰键的译词上屏或删除候选改为其他组合；配置冲突时朗读不会启用。配置文件中的 `[shortcut] speak_candidate = "ctrl"` 表示 `Ctrl + 序号`，空串关闭。此设置只用于 Windows 修改版。

先在电脑启动随修改版提供的手机朗读连接工具，把配对页中的完整地址发到安卓手机。手机连接蓝牙耳机、打开接收页，选择英文音色并点“启用朗读”。请保持页面在前台；后台或锁屏会暂停，返回后重新启用。关闭电脑连接工具即停止转发。此功能不需要开启云联想；中文候选需要已有英文译词，英文候选可直接朗读。

默认使用同一局域网；不同 Wi-Fi 或手机使用移动网络时，可选择临时公网连接方式。电脑保持连接工具运行，手机打开新的 HTTPS 配对地址即可；重启后需要重新配对。该方式通过 Cloudflare 转发主动点击的英文，请勿公开完整配对链接。

系统英文试听正常，但页面没有列出英文音色时，点“重新检测音色”，或选“系统自动选择英文”并点“试播英文”。确认听到声音后再启用朗读。若网页仍无法发声，可改用独立 Chrome 或 Edge 浏览器打开同一完整地址重试。

也可使用个人试用版「青简朗读」安卓 App：内置英文离线音色，粘贴同一完整 HTTPS 配对地址后启动后台接收。通知栏可停止，音量支持单独调整，朗读时请求降低音乐声。首次请先离线试播，并在手机后台省电设置中允许运行；锁屏长期接收及耳机音量需按实际设备验证。使用 App 时请暂停网页接收，避免重复播放。

App 0.1.1 起可点“扫码连接”，首次允许相机权限后扫描电脑配对页的二维码，自动保存地址并连接。电脑连接工具重启后扫新码即可；只重开手机 App 时可继续使用已保存的地址。二维码含配对信息，请只供自己的手机扫描。

App 0.1.2 起可选择八种内置英文音色（四男、四女），选择后点“离线试播英文”比较；后续朗读会记住该选择。音量增强支持 50%～400%，升级会保留原设置。增强越高可能改变声音质感，最终响度还受到手机媒体音量和耳机设置影响。

App 0.1.3 起可查看“最近接收”和“最近朗读”。点击电脑喇叭后，先看接收时间是否更新；已收到而无声时，最近朗读会显示所选音色的合成、播放或中断情况。离线试播不会改变最近网络接收记录，服务停止也保留最后音频提示。

App 0.1.4 配合修改版电脑设置的“手机朗读”页，可以集中启动连接、显示配对二维码、暂停 / 启用朗读、选择音色及在手机试听。手机连接后，电脑可发送已解压的兼容模型文件夹，手机自动下载并加载；以后新增兼容音色无需重装 App。首次使用需要更新一次手机 App。新模型若需要更新的推理引擎，仍需更新 App；具体支持的目录结构见随修改版提供的手机朗读说明。

App 0.1.5 将 Kokoro 的 af_heart 美式女声直接内置到安装包，手机选「女声 1 · af_heart」、电脑选「内置 · 女声 1」即可，不用发送模型文件夹。新安装默认使用它，升级保留原选择；首次准备模型时请稍候。其余七个音色仍保留。安装包和安装后存储占用会明显增加，请预留至少 1.5 GB 空间。

App 0.1.6 修复部分设备短词显示朗读完成却无声的问题，补足播放开始所需的音频缓冲。播放超时会明确提示，不再显示完成。可覆盖安装并保留配对与音色设置，电脑端无需更新。

个人修改版已将「手机朗读」入口接入新版设置界面，连接、扫码、音色选择与暂停用法相同。操作失败时可在发送音色按钮下方看到原因；旧版设置也保留该页。独立测试配置不操作实际手机连接。

长期个人使用可选择 Tailscale 连接方式：电脑和手机登录同一私人网络后，首次把固定 HTTPS 配对地址填入 App，连接工具正常重启后仍可复用。电脑和手机均须保持 Tailscale 在线；主动重置配对、更换设备或地址变化后需要更新。仅支持获准访问该电脑服务的私人网络设备。

## 生词

**橙色的译词为生词**：它在上屏时出现在候选窗口中的次数不足三次。达到三次后自动恢复灰色，不加图标、不弹出提示。
只按上屏那一刻屏幕上的那一页计算，逐键刷新时短暂出现的不计。

## 直接输出译词

输入拼音时，不选候选本身，而是输出其旁边的译词：

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 1` 至 `9` | `Ctrl + 1` 至 `9` |
| 上屏第二条译词（候选右侧有两条时；日文不带注音） | `⇧⌥ + 1` 至 `9` | `Ctrl + Shift + 1` 至 `9` |

也可以直接用鼠标点候选右侧的译词，点哪条上屏哪条（青简渲染器）。学习记录与选中该候选相同。候选没有对应译词时按键无效。

## 删除不需要的候选

输入拼音时按 `⇧ + 数字`（Windows：`Shift + 数字`）删除当前页第 N 个候选：
用户自造的词、云端选过的词整个删除；词库中的词不删除，但清除对它的全部学习记录，恢复原始排序。
删除后拼音行下方短暂显示结果（「已删除用户词「…」」，或词库词无学习记录时的「没什么可删」），输入下一个键即消失。

## 翻译选中的文字

按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）将应用中选中的文字翻译为学习语言，需打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。

## 修改快捷键

上述三组修饰键与翻译快捷键均在「设置 → 快捷键」录制修改。
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页）；Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获，因此缺省使用 `Ctrl`。
全部按键见 [按键与快捷键](../getting-started/keys.md)。

## 学习方式

- 选过的词、同一段拼音下选过的词、连续输入的词序列，均在本机记录，整句转换与排序据此调整。
- 连续选出的两个词合起来不在词库中且选择次数达到阈值时，自动记为一个词。
- 全部在本机，不上传。文件位置与清除方式见 [数据与日志](../help/data-and-logs.md)。
