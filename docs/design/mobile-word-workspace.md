# Android 单页词汇学习

0.2.21-dev（构建30）按 [确认的交互原型](mobile-word-workspace.html) 实现原生词卡。`WordStudyActivity` 组织材料、跟读/练习工作区、折叠记录、页内老师与小结，固定底栏显示当前主要操作。旧 `OralActivity` 仅保留选词/重定向，录音和当前词问答均不再打开独立工作页。

`word/State` 保留任务和草稿，视图拆为 OralView、PracticeView、TeacherView 与 Fold。进度更新不重建输入框，旋转复用任务，进入页面不自动请求服务。题号与拼写草稿持久化到 `word_workspaces`，成绩由 PracticeStore 固定题号去重；修改笔记使当前题目失效，保留既有历史。

## 评测边界

采用 [讯飞流式WebAPI](https://www.xfyun.cn/doc/Ise/IseAPI.html) 固定主机WSS。AppID/Key/Secret全部由Keystore AES-GCM加密，独立于文字AI；设置页禁止截屏、保存输入状态和自动填充。凭据不进入安装包、日志、AI或配对。连接测试仅执行鉴权握手，不代表已验证AppID/题型授权。

不增加依赖：wire/TlsChannel使用平台TLS、系统信任、主机名及SNI校验，固定主机、拒绝跳转与扩展，验证101和Accept；Frames只实现掩码发送、分片接收、ping/pong及大小/数量限制。连接和读取均有超时，取消关闭套接字。Channel供测试替换，不改变生产信任策略。

客户端验证16kHz单声道PCM16 WAV，去44字节头，每40ms发送1280字节。单词使用BOM加`[word]\n`，短语/句子使用BOM加`[content]\n`，请求百分制、多维度和音节反馈、UTF-8响应。解析有界XML并拒绝实体/DOCTYPE和无有效录音结果；缺失维度为null，不以零分替代失败。

停止录音后自动保存，明确点击评测才上传。取消/失败保留完成录音，不自动重试。评测独立ID绑定录音、目标、词条快照和音频SHA-256，只对running状态写一次结果；删除/变化/取消后拒绝晚到结果。历史成功评分可展开查看。SQLite v9从v1～v8保留迁移，旧录音回填目标及模式，不生成历史分数；删除录音删除评分，清空学习删除工作区。

## AI 与声音

页内问答复用手机AI、Koog及会话目录，附少量已保存讯飞评分和当前词实际练习；工具概览和每日事实也可读取成功评分。AI不能读取音频/讯飞凭据，不能修改成绩或主动提交评测。解释按钮显式发送，回答作为建议，与服务分数区分。

中文播报复用原Kokoro权重，补约16.4MiB中文词典、jieba数据及许可，无第二套权重。英文保留八个选择，中文单独选择八个音色。SpeechPlan限制文本并拆分中英、重采样合并；SpeechPlayer缓存对应模型，保留焦点/增益/语速逻辑。试听不计收到/播放次数，录音中禁播，状态及喇叭选择态显示反馈。

## 验证

`assessment` 覆盖协议、加密、取消/删除/写入边界和配置页；`workspace` 覆盖实际AudioRecord/保存/MediaPlayer、旋转幂等、页内练习/小结；`study` 使用真实软键盘验证页内AI和离线草稿；`bilingual` 使用真实中英模型和AudioTrack。`assessment_live` 需显式运行，读取后立即删除一次性私有配置，仅提交本机合成英语，结果不写学习库。

真实讯飞联调已返回有效单词/句子分数和词级结果，证明协议与解析可用，不代表评估过真实用户读音。一加手机麦克风、蓝牙听感及网络仍需覆盖安装后确认。
