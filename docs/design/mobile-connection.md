# 顶部连接与扫码

2026-10-20用户确认HTML后在0.2.22-dev落实原生控件和60秒截止，参见[交互预览](mobile-connection-preview.html)。重试计时使用单调时钟，成功清零；超时递增会话代次、断开请求并停止前台接收。已有轮询异常负责网络变化后的恢复，手动停止和超时后不自启。

- 连接状态及扫码保留在标题右侧，不占额外一行，不打开独立连接页或连接面板；学习、词库、AI老师使用同一个连接状态。
- 已连接、连接中或自动重连中，点连接控件直接停止，短暂显示「正在停止」，完成后显示「重新连接」。停止后旧回调不得恢复连接。
- 连接控件不常驻停止方框。已连接为绿点加文字；连接/重连中显示转圈加文字；停止后才显示圆箭头加「重新连接」，保留整个控件可点的行为和无障碍说明。
- 顶部连接控件和扫码图标使用透明背景，停止后的重新连接也不加绿色底块。点击保留轻微透明度/缩放反馈，44px触摸区域和键盘焦点提示保留。
- 每轮连接恢复最多持续60秒，包含请求与退避等待，使用单调时钟。失败重试不重置截止时间；成功连接后结束本轮。网络变化也不延长本轮。
- 超时取消进行中的请求与排队重试，控件变为「重新连接」，不自动重新开启下一轮。即使网络恢复，手动停止或超时后的状态也须等用户点击才启动。
- 用户点击重新连接或识别新配对后开启新一轮。重连时顶部显示剩余秒数，无障碍说明包含重试次数和停止操作。
- 扫码界面固定竖屏，无旋转按钮；使用标准手电筒开/关图标和「打开／关闭手电筒」说明。离开扫码关闭手电筒，取消扫描保留原配对及连接状态，成功识别自动连接。

预览仅模拟连接和取景，不访问相机或网络；「模拟断网」「网络恢复」「跳到一分钟上限」位于手机框外，仅用于检查流程，不进入正式App。浏览器已检查连接/重连取消、上限、超时后不自启、三个主页状态共享、扫码开关及320px窄屏。
