# 词条内的手机 AI 学习资料工作流

Android 0.2.20-dev（构建29）将词条补全改为手机直接请求自身 Credentials 中的 API。原0.2.19电脑单释义入口不再由手机调用，兼容服务仍见 tools/speech-relay 的旧版协议说明。

## 运行边界

从词条按钮进入，携带当前英文、已有笔记/资料和学习偏好，不打开对话、不发整份词库、不发录音或电脑配对凭证。最多100字英文，手机必须已有有效HTTPS API配置；不需要电脑在线。复用原 Client 的鉴权、拒绝重定向、请求大小、响应上限和取消机制。

开启工具时复用真实 Koog Runner，只注册 prepare_word_materials，参数包含 meaning、example、translation、collocations（1～3条phrase/translation）和usage。词条ID不作为可写参数，目标绑定于用户打开的当前页。工具只在内存中准备提案；Agent整轮完成后再提交，失败、取消或后续模型请求失败均无资料写入。关闭工具时仍通过同一Koog图完成一轮文字请求，要求严格JSON；不会暗中切换协议或自动重试。工具模式可能调用多轮模型并产生用量。

Pack 校验字段白名单、类型、长度、中英要求及例句包含目标原词。缺字段、额外字段或格式错误均拒绝整包，不用半份回答填入手机。模型不能设置成绩、复习日期、其他词或配置。学习资料保持AI来源提示，不能把完成生成视为已学会。

## 存储与保护

SQLite v8新增word_materials，按word_id保存结构化资料，并在删除词条时清理。v1～v7升级保留原词汇、note_revision、词卡、会话和测验。ActionStore.approvedCard优先读取完整资料并兼容旧版词卡，现有填空练习可直接复用例句；旧词卡不被重写。

Snapshot绑定当前id、英文、笔记、note_revision、现有资料和最新旧词卡。事务内检查快照再同时保存笔记和完整资料；保留已有非空笔记和旧例句，只补空缺。写入失败回滚整包。提交前检查手机API配置未变化；退出、取消、清空词条、并发手动编辑（包括同值保存或改后清空）都阻止旧提案写回。

撤销只在完整生成后快照仍匹配时恢复本次前的笔记与资料；不删除原词条、旧词卡、练习或成绩。撤销入口在本次页面会话保留。新增完整资料也会阻止旧AI新词操作把该词误删。清空学习资料同时清理word_materials。

## 交互

资料不全即显示「AI补全学习资料」，即使中文笔记已经存在。处理时禁用重复按钮，显示阶段、进度条及取消；未配置时提供进入手机AI设置的入口。只刷新资料区域，不重建辨析输入框。旋转保留Job，不重新发送；资料保存后原页展示例句、搭配和用法，试听复用既有引擎且不写播放计数。无新增聊天记录，已有对话仍可继续提问。

## 验证

安卓instrumentation `-e notes true` 验证无电脑/无配对、手机key和model、真实Koog及纯文字模式、整包校验、事务失败回滚、旧例句保留、手动编辑保护、手机配置更改、取消、后续模型失败、屏幕重建、草稿保留、离线资料及练习例句复用。`-e migration true` 覆盖v1～v7迁移。使用受控HTTPS响应和测试密钥，不复制用户电脑密钥到模拟器。
