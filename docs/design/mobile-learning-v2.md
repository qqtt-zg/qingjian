## 信息架构

- 四个主入口为学习、词库、AI老师、我的，保留已确认的青绿与米白风格。
- 系统设置只在“我的”标题栏出现，业务统计不混入连接状态。四页连接与扫码保持同一靠右位置，背景透明，没有停止方框。
- 四个主标签页通过底部导航切换，不显示返回箭头；子页保留常规返回图标。AI老师标题左侧保留对话选择按钮。
- 学习首页围绕拼写重点与继续学习，独立小测是次入口。词卡在资料、拼写、跟读间切换，当前词追问留在原页。
- “我的”收拢真实记录的展示位置：概览、日期记录、学习档案、token及评测次数、同步与备份。详细设置进入子页，不新增底部标签。
- “电脑来源”统一放在“我的”，词库只保留查词与学习入口。学习日历默认展示所选日期的一周，可展开月历；收起保留选中日期，周/月均可前后翻阅，不允许选择未来日期。
- “我的”首屏直接显示语音评分的今日提交次数、每日免费额度参考及本机估算余量，点击进入次数详情。估算不小于零；平台实际余额仍显示未知，参考值可在详情调整，演示数据不会计费。

## 可以体验的流程

1. 开始练拼写，隐藏英文标题和例句；输入recieve展示错误位置，再遮住重拼。读音、首字母和答案辅助分别留痕，目标词修正使用绿色突出。
2. 搜索词库，打开词卡；跟读模拟开始、停止、取消评测、重试与评分反馈。录音和评分明确标注演示，实际不会访问麦克风或TTS。
3. 选择今日、本周、待巩固或自选范围及题数；按现有演示词数量组卷。小测隐藏答案，可返回、跳过、暂停、查看答题卡和修改草稿，交卷后统一按实际输入计分。
4. 考后从错词回到盲写，或在AI老师中解读示例小测结果。原页提问与全局对话均由预置回复驱动，参考记录可展开。
5. 点击“我的”日历日期查看对应示例事件；纠正或删除记忆，再运行全量分析。分析分批推进，可暂停及继续，完整覆盖后才显示完成，明确纠正和删除不会被覆盖。
6. 查看AI任务的输入/输出/缓存和未知推理token；缓存是输入子项。评测次数展示本App提交、成功/失败/取消及可调的每日参考，不冒充账号余额。
7. 演示电脑词库单向同步和手机档案备份；断线排队，手动停止的连接不自行启动，重新连接后继续待备份任务。备份清单排除密钥、模型与配对凭证，录音默认关闭。
8. 顶部状态直接停止或重连；失败重试不延长60秒截止，超时后只保留重新连接。扫码固定竖屏、无旋转按钮，手电筒开关改变图标和文字，退出即关闭。

## 原型边界

底部框外有演示标识、模拟断网/恢复、跳至一分钟上限和重置按钮，不进入正式App。所有演示状态只保存在原型会话，重置不会读取或删除手机、模拟器或电脑数据。

输入框与按钮直接响应本地事件，兼容预览沙盒不允许表单导航的限制。未调用网络、音频、相机、文件传输或真实AI接口。浏览器验证不等于Android软键盘、麦克风、蓝牙或后台服务的真机验证。
