# 手机朗读设置与可传输音色

目标：青简设置新增「手机朗读」页，包含连接启停、二维码、手机状态、朗读开关、音色选择、试听、发送解压后的模型文件夹。个人版当前只在 Windows 显示。Android 更新一次接收协议后，兼容音色通过网络传输，无需再次打包 APK。

实现顺序：Python 本机管理接口及受配对鉴权保护的包下载 → Android 动态模型加载、控制同步与设备回报 → Windows 原生子组件与后台管理命令 → 构建、隔离传输/播放测试、部署本地设置程序与交付 APK。

协议：本机发布凭证管理连接、开关和模型，手机接收凭证下载包并提交设备状态；手机不能控制电脑或提交朗读正文。原有英文事件兼容旧 App。控制修订号参与长轮询唤醒；手机回报安装状态、音色数量、播放状态与传输进度。

音色包只含数据，支持当前 sherpa-onnx 的 kitten、vits、kokoro 配置；文件白名单路径映射、包 SHA-256、总量/文件数限制、私有暂存目录与原子安装。禁止绝对路径、父目录、反斜杠路径和符号链接；下载不跟随重定向。加载新模型与音频生成使用同一工作线程，异常回退内置模型并显示失败原因。不承诺支持需要新版原生推理库的模型。

二维码由本机 JS 库生成，旧 WinUI 设置使用图片控件，新版 `apps/settings` 在 bamboo-slip 上按二维码模块绘制；管理命令通过本地 Python 辅助程序完成，运行于后台，不阻塞输入与界面。新版设置用常驻后台线程顺序处理操作、每两秒取手机状态，待交付的操作结果优先于轮询，避免忙状态不结束；错误与状态同时显示在发送按钮旁。使用 `--config` 指向隔离配置时禁用真实服务操作，离屏测试不启动或停止用户连接。个人开发版使用已安装的 Python 和 Node.js，随当前测试目录部署辅助文件。
