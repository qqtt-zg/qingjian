# 手机学习会话与 Agent 框架评估

0.2.16-dev 的自动操作、撤销和原生 UI 规则见 [原生交互设计](mobile-native-feedback.md)，覆盖下文 0.2.15-dev 的手动确认策略。近期操作的实际 `practice_results` 进入下一次上下文（包括纯文字模式），只有提交过的答案才有结果；不以题目准备或朗读次数推断掌握。

## Koog 接入：0.2.15-dev

用户明确要求接入后，将正式答疑的手写循环替换为 Koog 1.3.0 `GraphAIAgent`。Kotlin 升级为 2.3.10，AGP 为 8.13.2；继续使用 Gradle 8.13、JDK 17、minSdk 26。选用 `ai.koog:agents-core:1.3.0`，不添加整个提供商聚合包；该模块仍有 Koog 自身的客户端、Ktor 和序列化传递依赖，并非零额外体积。

- Koog 图执行首次模型请求、串行白名单工具、工具结果回传和后续请求。注册的五项工具从现有 `Catalog` 创建，实际查询/草稿继续通过原 `Executor`；保存词卡、练习和朗读仍需原生操作卡确认。
- `agent/Transport` 实现 Koog `PromptExecutor`，复用现有 `Client.turn`。用户原有 HTTPS 地址、模型与密钥不迁移，不要求切换服务商。`agent/Messages` 映射文字、工具 ID 和结果，不发送推理内容、原始服务商扩展或录音。
- 正式答疑工具开启时最多三次请求、每次最多四项调用，第三次为 `tool_choice=none`；工具关闭时仍经 Koog 图执行，但只请求一次且不发送 tools 字段。包含文字与工具的混合回复优先处理工具，不会提前结束回答。失败不自动重试，不自动降级到第二套代理循环。
- 每次明确发送新建一个代理运行。SQLite 会话目录、问答关联、草稿、摘要、检索与操作卡去重保留；不启用 Koog 的第二套持久记忆或检查点。已有摘要整理和配置连接测试仍复用原文字客户端，不经过工具代理，不增加额外请求。
- 请求前后和每项已注册工具前后检查取消及150秒期限；用户取消仍断开当前 HTTP 连接。保留本机受控 HTTP 错误，避免框架异常包装丢失提示。Koog 图另设十次节点迭代上限，网络请求计数以执行器的三次硬限制为准。
- 不安装 Tracing、远程调试或遥测功能。Android 的 kotlin-logging 后端可直接写 Logcat，因此在创建代理前切换为关闭级别的 DirectLoggerFactory；SLF4J 使用 NOP 并排除传递的 simple 后端，避免正文/工具参数日志。
- APK 中保留 Koog Apache-2.0 许可证、NOTICE 以及第三方来源说明。未更改手机配对、后台接收、音色、录音或更新发布方式。

版本化 API 依据为 [Koog 1.3.0 源码](https://github.com/JetBrains/koog/tree/1.3.0)，包括 `GraphAIAgent`、`PromptExecutorAPI`、`MessagePart` 和 `Tool`。Android 编译工具依据为 [AGP 8.13 发布说明](https://developer.android.com/build/releases/agp-8-13-0-release-notes) 与 [Kotlin/D8 兼容表](https://developer.android.com/build/kotlin-support)。最终采用的 API 以固定版本源码和实际编译为准，未照搬 develop 分支旧示例。

验证：独立 Android 16 x86_64 模拟器通过 Koog 新增探针及十二组回归。新增探针检查真实调用栈经过 `ai.koog` 图节点、文字与工具混合回复不提前结束、工具 ID、自定义模型、无工具字段的纯文字模式、原 HTTP 401 提示、未知工具不执行、取消时不创建草稿和库日志关闭。其他回归覆盖三轮请求上限、原生操作卡、会话/摘要/旧资料、测验、真实录音与双引擎合成。使用假密钥和受控网络响应，未调用用户真实 AI 服务；旧版 Android 与手机实机未另行验证。ARM64 包为构建24，同签名，439880372字节，比构建23增加6080281字节（约5.8 MiB）。

## 0.2.14-dev 的静态评估

该阶段先完成会话隔离、长对话摘要和相关学习记录检索，使用现有 SQLite、HTTPS 客户端及原生待确认操作卡，当时没有引入 Koog 或更改编译依赖。后续明确接入的结果以上一节为准。

核对的 Koog 稳定版本为 [1.3.0](https://github.com/JetBrains/koog/releases/tag/1.3.0)，发布于 2026-09-24。[该版本 README](https://github.com/JetBrains/koog/blob/1.3.0/README.md#requirements) 要求 Kotlin 2.3.10+、JDK 17+，并列出 coroutines 1.10.2、serialization 1.10.0、datetime 0.7.1。本工程为 Kotlin 2.0.21、JDK 17、Gradle 8.13、AGP 8.11.1，Android minSdk 26。

JDK 符合要求，Kotlin 版本低于官方要求。这是暂缓接入当前稳定版的依据，并不等于 Koog 不支持 Android。此次为文档和工程配置的静态兼容评估，没有升级工具链、解析完整依赖树或测量接入后的 APK 增量，也没有验证真实中转站兼容性。旧版 Koog 是否可用不作为本次发布依据。

未来迁移须单独验证 Kotlin/AGP、Android 8+、取消与生命周期、用户自定义 HTTPS 地址及模型、无工具纯文字模式、操作确认边界、包体增量和数据库保留。Koog 可以承担编排，不能代替本机工具授权、实际成绩与资料管理。

## 当前实现：0.2.14-dev

- SQLite v4 新增 `conversations`，以不透明 topic 为主键，保存词条归属、标题、摘要、覆盖消息 ID 和修订号。升级时将旧 `general` / `word:<id>` 纳入目录，消息和操作卡仍使用原 topic，不改 ID。消息增加唯一 `reply_to` 关联，避免旧待问在多轮后重试时与其他问题配错；升级只回填可靠的相邻问答，孤立旧讲解仍保留。
- 通用学习与每个词条各有会话目录；新建会话不会删除旧会话。标题可改，切换时草稿分别保存；旋转保留当前会话和草稿。单词页选择最近的真实已保存回答，并能打开其来源会话。
- 每次明确发送才组装上下文：固定教学规则、保存的学习偏好、当前词条、相关词汇/错题、摘要、近期已完成问答、最新问题。摘要、笔记和检索结果都以数据身份提供，不能变成系统指令或执行授权。
- 近期历史按完整问答块选择，至多六块、16000 字符。单条用户消息至多4000字符、助手消息至多7000字符，超长时注明截断；旧版孤立助手消息兼容保留。不发送失败/待问条目作为已完成历史。
- 自动摘要默认开启，可在「对话与工具」关闭、查看或清除。未摘要部分超过十二块时，一次发送最多额外请求一次 AI，总结较早内容并保留近六块。单次整理最多十二块、18000字符，旧摘要最多3000字符；超多旧记录分多次发送逐步整理，并非一次覆盖所有历史。
- 摘要请求不带工具，模型输出最多3000字符。失败不自动重试，正式回答回退到已有摘要和近期问答，并提示摘要未更新。取消或正式回答失败不保存新摘要；成功后的缓存写入检查会话修订号和原问题存在性，清空后的晚到结果不重建缓存。
- 摘要属于有损缓存，原始消息不删除，不用它改学习偏好或判定掌握。上下文预算以字符计，尚无各服务商精确 token 计费估算；特别长的旧记录仍可能暂未涵盖，不声称完整记忆。
- 相关记录采用本机有界字面检索：提取最多八个词段，返回最多四条词汇和三条相关错题；明确问复习/错题时可取最近仍答错的题。不是向量或语义检索，中文整句、屈折词形和同义词不保证匹配。既有查询工具可继续补查。
- 原五项工具白名单、原生确认、实际测验计分、录音本地保存和密钥边界保持不变。摘要会增加 API 用量，界面在开关说明及请求进度中告知。
- 清空本页同时清空该会话摘要和草稿，已确认词卡继续保留；清空全部学习资料删除会话、摘要和草稿，保留 API/连接/声音/自动摘要设置。
