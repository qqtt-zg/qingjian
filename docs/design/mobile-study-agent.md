# 每日学习 Agent：0.2.18-dev

对应用户确认的 [学习交互](mobile-study-flow.html)。原生实现位于 `learning/daily`，使用既有 Koog 1.3.0、SQLite 和 PreviewSpeech，不增加依赖。

## Agent 与程序的职责

首页「安排今天学习」才启动模型请求，进入首页、恢复页面或旋转不请求。已有今日或未完成计划时显示继续，不创建平行计划。每轮请求最多三次模型交互，第一轮只开放 `get_study_context`，模型看到事实后才开放本阶段提案。拒绝本轮未开放的调用。

- CREATE：读取偏好、有限词库、真实到期项及近14天作答/最近7轮每日结果，提出词汇、短例句和选材理由。通常少量新词与复习词，新增不得超过用户偏好（最高8词），计划材料总数最多10项。
- ADAPT：读取当前练习的正确/辅助情况，选择后续小测的重点、类型和1～5题；不能替换已开始的小测或已提交记录。用户自然语言调整要求随计划保存；之后自动调整不能超过该次确定的题数限制，只有新的明确调整可改变限制。
- SUMMARY：读取真实小测、辅助、重播及自评，保存回顾建议。分数始终由本机计算，AI 的文字不作为成绩或已掌握状态。

模型工具只准备提案，不立即修改资料。图成功结束、未取消且数据库修订/清空代号仍有效时，事务校验与提交。失败、取消、没有提案、非法词ID或不适用题型都不显示为已成功执行；原进度保留，不自动重试。

## 执行与交互

流程为 LEARN → PRACTICE → ADAPT → EXAM_INTRO → EXAM → RESULT → REVIEW → SUMMARY → DONE。没有复习项时跳过 REVIEW。

学词一屏一个快照，词和例句可分别听；练习允许提示、点选即时反馈，选项小喇叭不提交答案。结束练习后由真实 Agent 根据结果调整；网络不可用可明确按原先准备的小测继续，不伪造 AI 调整。

独立小测统一结束后才显示反馈。包括词义/英文选择、具备资料时的搭配填空、拼写和听辨。听辨的播放状态遮蔽目标英文；可重播，使用文字辅助单独记入该题。拼写草稿落盘，键盘弹出时主按钮仍固定可见。

旧词先回忆、再看答案、自评；自评不并入测验成绩。小结分开展示独立答对、辅助、看完词数和自评词数。问老师携带当前词条和问题草稿，返回时任务状态保留。

## 资料与评分

SQLite v6 增加 `study_meta`、`study_plans`、`study_items`、`study_questions`、`study_reviews`，升级保留 v1～v5 的词汇、会话、测验和配置。题目与答案使用稳定快照，重复提交不重复计分。练习不写入正式测验表；每日小测使用既有评分函数，辅助状态在每日明细中保存，听辨分项在每日结果及复习表中标记。

已保存资料离线可继续，AI 回顾失败仍可查看本机结果并结束本轮。清空学习资料同时清空计划和复习状态，提升清空代号；晚到 CREATE 不能重新生成被清空的资料。旧答疑词卡被计划引用后不能通过撤销删除，避免悬空词条。

初步分项复习规则：看完新词安排次日再见，未独立答对/没想起来为1天；不同日期连续正确逐步使用1、3、7、14、30天，同一天重复作答不增加间隔等级。听辨、题型与自评分别记，不宣称等价于掌握、标准语言等级或已验证的个性化记忆模型。

## 本版边界

不包含后台每日定时触发、电脑定时周总结、完整学习资料包推送、正式证书考试、自由表达自动判分或口语自动评分。已有录音与自评保持独立。学习阶段顺序由应用保证，Agent 负责内容、后续小测调整和回顾，不让模型控制任意页面或写成绩。

模拟器使用假密钥与受控 HTTPS 模型响应验证实际 Koog 图与工具结果传递。程序流程、取消、恢复和计分测试不能证明真实模型的例句自然度或教学效果；真实服务、真实学习者及手机仍需覆盖安装后验证。
