# 每日学习 Agent 实施计划

用户已确认学习路线、交互原型及继续接入真实 Agent。直接在当前个人分支执行，保留其他未提交改动，不提交或推送 Git。

**Goal:** 用户从首页一键开始，由 Koog 根据实际词汇、作答和偏好准备本机计划，按真实结果调整后续小测，完成后生成回顾。

**Architecture:** 独立 `learning/daily` 模块使用同一 SQLite；模型通过专用工具提出资料和后续重点，应用校验后提交。计分、任务推进、复习日期由程序维护。Koog 图与 HTTPS 传输可接受专用工具集，原五工具答疑保持兼容。

**Tech Stack:** Kotlin Views、Koog 1.3.0、系统 SQLite、既有 PreviewSpeech；不增加依赖。规格依据 `docs/design/mobile-study-flow.md` 与本计划的执行约束。

## 执行约束

- 只实现用户主动开始的一轮每日学习，不加入后台定时任务、远程推送和自动口语评分。
- 问题、提示与独立测验分别记录；唯一题目键防重复计分。AI 不能直接写成绩或完成状态。
- 新计划不覆盖未完成计划；调整只改变未开始的小测，不删除原有词汇或已完成结果。
- 每个 AI 操作最多三轮模型请求，可取消；提案只有在本轮成功且数据库修订未变化时提交。失败保留已有学习资料，允许明确沿用原计划。
- 已保存计划离线可继续；没有 AI 配置时显示配置入口，不伪造 Agent 计划。
- SQLite v6 增表迁移，覆盖安装保持包名和签名。独立模拟器使用假凭证与受控模型响应验证，真实服务质量另行确认。
